# 源代码部署说明

> 前提：先准备好配置，详见[配置生成器使用说明](配置生成器使用.md)。真实配置含
> 登录 Cookie，必须放在仓库目录之外并限制文件权限。

源码部署适合已经有 Python 的服务器。它不会常驻 Chromium：`systemd timer` 只在
设定时刻启动 Python 与 Headless Shell，任务结束后全部退出，平时几乎没有额外
内存占用。

## 1. 运行要求

- Python 3.10 或更高版本
- systemd
- 可访问 PyPI、Playwright CDN、抖音聊天页与一言接口
- 建议至少保留 1.5 GiB 可用内存和 600 MiB 可用磁盘

Playwright 官方支持 Debian/Ubuntu 等系统。AlmaLinux 9 不属于官方支持范围，但
可安装下列最小运行库后使用 Ubuntu fallback Headless Shell。上线前必须执行本文
的空白页启动与 `--preflight` 验证。

## 2. AlmaLinux 9 最小浏览器依赖

以下命令关闭弱依赖，不会安装桌面环境、LLVM 或完整显卡驱动：

```bash
dnf install -y --setopt=install_weak_deps=False \
  atk at-spi2-atk at-spi2-core \
  libX11 libXcomposite libXdamage libXext libXfixes libXrandr \
  mesa-libgbm libxcb libxkbcommon
```

## 3. 创建专用用户与目录

```bash
useradd --system --create-home \
  --home-dir /var/lib/douyin-spark-flow \
  --shell /sbin/nologin douyin-spark-flow

install -d -m 0755 /opt/douyin-spark-flow
install -d -o root -g douyin-spark-flow -m 0750 /etc/douyin-spark-flow
install -d -o douyin-spark-flow -g douyin-spark-flow -m 0750 \
  /var/log/douyin-spark-flow /var/lib/douyin-spark-flow
```

专用用户没有登录 Shell，也没有权限修改源码或配置；它只可写自己的日志和运行
状态目录。

## 4. 拉取代码并安装最小 Python 环境

```bash
git clone https://github.com/hrkj-zjx/DouYinSparkFlow.git \
  /opt/douyin-spark-flow/app

python3 -m venv /opt/douyin-spark-flow/venv
/opt/douyin-spark-flow/venv/bin/python -m pip install \
  -r /opt/douyin-spark-flow/app/requirements.txt
```

只安装 Chromium Headless Shell，不下载完整有界面浏览器：

```bash
PLAYWRIGHT_BROWSERS_PATH=/opt/douyin-spark-flow/browsers \
  /opt/douyin-spark-flow/venv/bin/python -m playwright install \
  chromium --only-shell
```

AlmaLinux 不是 Playwright 官方支持平台，基础镜像中预装的库也可能不同。安装后先
定位 Headless Shell 并检查动态链接；命令有任何 `not found` 输出时不要启动任务，
应先用 `dnf provides '*/缺失库名.so'` 安装对应运行库：

```bash
HEADLESS_SHELL=$(find /opt/douyin-spark-flow/browsers \
  -type f -name chrome-headless-shell -print -quit)
test -n "$HEADLESS_SHELL"
ldd "$HEADLESS_SHELL" | grep 'not found' || true
```

## 5. 安装站外配置

把生成的 `.env` 内容保存为 `/etc/douyin-spark-flow/config.env`，再限制权限：

```bash
chown root:douyin-spark-flow /etc/douyin-spark-flow/config.env
chmod 0640 /etc/douyin-spark-flow/config.env
```

生产环境建议保持以下低资源配置：

```dotenv
BROWSER_HEADLESS=true
BLOCK_BROWSER_RESOURCES=true
LOG_LEVEL=INFO
```

程序通过 `DOUYIN_ENV_FILE` 自行读取该文件，Cookie 不会写进 Git、镜像层或
systemd 的 `EnvironmentFile` 转储。

## 6. 安装 systemd 单元

```bash
install -m 0644 \
  /opt/douyin-spark-flow/app/deploy/systemd/douyin-spark-flow.service \
  /etc/systemd/system/douyin-spark-flow.service
install -m 0644 \
  /opt/douyin-spark-flow/app/deploy/systemd/douyin-spark-flow.timer \
  /etc/systemd/system/douyin-spark-flow.timer
install -m 0644 \
  /opt/douyin-spark-flow/app/deploy/systemd/douyin-spark-flow-preflight.service \
  /etc/systemd/system/douyin-spark-flow-preflight.service

systemd-analyze verify \
  /etc/systemd/system/douyin-spark-flow.service \
  /etc/systemd/system/douyin-spark-flow.timer \
  /etc/systemd/system/douyin-spark-flow-preflight.service
systemctl daemon-reload
```

服务默认限制为 1 个 CPU、1 GiB 软内存和 1.5 GiB 硬内存，并由 systemd 阻止
同一个 oneshot 服务重叠运行。

## 7. 启用前安全验收

先做配置校验，不启动浏览器：

```bash
sudo -u douyin-spark-flow env \
  DOUYIN_ENV_FILE=/etc/douyin-spark-flow/config.env \
  /opt/douyin-spark-flow/venv/bin/python \
  /opt/douyin-spark-flow/app/main.py --validate
```

再启动只读预检单元。它与正式任务采用完全相同的 systemd 沙箱，但只注入 Cookie、
打开聊天页并等待好友列表，不点击好友、不定位输入框，也不发送消息：

```bash
systemctl start douyin-spark-flow-preflight.service
systemctl status douyin-spark-flow-preflight.service --no-pager
journalctl -u douyin-spark-flow-preflight.service -n 100 --no-pager
```

两项都通过后再启用每天 09:00（Asia/Shanghai）的定时器：

```bash
systemctl enable --now douyin-spark-flow.timer
systemctl list-timers douyin-spark-flow.timer
```

## 8. 日志与维护

```bash
journalctl -u douyin-spark-flow.service -n 200 --no-pager
systemctl status douyin-spark-flow.timer
```

更新代码后重新安装依赖、执行 `--validate` 与 `--preflight`，确认通过后再保留定时
器。不要用 `systemctl start douyin-spark-flow.service` 做预检，因为该命令会执行
真实消息任务。
