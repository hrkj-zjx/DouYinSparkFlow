# DouYinSparkFlow 配置生成器

## 1. 配置生成器介绍

编辑器网址：[https://oilu.cn/DouYinSparkFlow](https://oilu.cn/DouYinSparkFlow)

这个可视化在线编辑器的作用是：填写配置信息后，自动生成可用于环境变量的配置内容。生成后可直接复制到 GitHub Secrets（环境变量）中使用，减少手动整理和配置出错。

**问：安全吗？**

答：该工具本质上是托管在本仓库 GitHub Pages 上的单页网页应用，相关源码已在 `docs` 目录开源，可自行查看与审计。配置填写、校验和 `.env` 生成均在当前浏览器页面内完成，页面不会把 Cookie 或配置提交给后端，也不会把 Cookie 输出到浏览器控制台。当前展示的网址不是 GitHub Pages 默认域名，是因为 GitHub Pages 博客绑定了自定义域名；同时该域名接入了腾讯云 CDN，访问速度会更快。

Cookie 在页面打开期间仍会存在于当前浏览器内存和输入框中。请只在可信设备及 HTTPS 页面上使用，复制完成后关闭页面，不要在共享电脑上填写真实 Cookie，也不要把生成结果发送到聊天工具或提交进 Git。

**问：为什么不再使用之前的本地 Python 脚本？**

答：在线编辑方式更轻量，无需配置本地环境，也无需拉取代码即可使用。

**问：为什么需要手动获取 Cookies？**

答：在线网页无法直接读取您电脑或浏览器中的本地数据。若改为远程服务端方案，不仅部署与维护复杂度更高，还需要在远程设备上登录账号。当前采用手动获取并填写的方式，可尽量保证数据在本地处理且不保存以此保障您的数据安全。

**问：配置生成器填写信息后需要保存之类操作吗？**

答：不需要。配置生成器会实时生成结果，填写完成后无需额外保存或提交，直接复制左侧生成的配置即可使用。点击任何单项复制按钮或“复制 `.env` 配置文件”时，页面都会先统一检查所有账户必填项；未通过时不会写入剪贴板。

## 3. 复制前校验规则

为避免生成后才在服务器上发现错误，单项复制和整份 `.env` 复制都会执行相同的前置校验：

1. 每个账户都必须填写非空用户名。
2. 每个抖音号只能包含字母、数字和下划线，而且多个账户之间不可重复；`demo_01` 与 `DEMO_01` 会被视为重复，因为 Secret 名最终会统一转为大写。
3. Cookies 必须能解析为非空 JSON 数组，数组中每项必须是对象，并包含 `name`、`value`、`domain`。校验错误只报告账户序号和缺失字段，不会显示 Cookie 值。
4. 每个账户至少需要一个非空目标好友。
5. Docker 执行时间不可清空；若浏览器组件异常返回空值，页面会自动恢复为 `09:00:00`，不会生成残缺的 CRON 配置。

## 4. `用户名`和`抖音号`获取

用户名只用于区分，可填写便于自己识别的非空名称。抖音号还会用于生成 Cookie 环境变量名，因此必须符合“字母、数字和下划线”的格式，并且在当前配置中保持唯一。

## 5. `Cookies` 获取

Cookie 的获取需要借助于 [Cookie-Editor](https://cookie-editor.com/) 浏览器扩展，请提前根据自己的浏览器环境安装此扩展。

使用目标账号登录[抖音创作者中心](https://www.douyin.com/chat)，登录成功后保持当前抖音创作者中心页面，打开 `Cookie-Editor`，按照下图所示导出 JSON 格式的 Cookies。请完整粘贴导出的 JSON 数组，不要改成 `name=value` 字符串。

## 6. `目标好友`获取

目标好友是配置当前账户要续火花的对象，可以多个，每添加一个需要回车一次，直到添加完所有续火花对象。

支持通过备注/昵称/抖音号等多种方式智能匹配，可以按需使用。

同一好友同时填写备注、昵称和抖音号时，程序只有在接口身份、全局会话和全部别名
都能建立唯一对应关系后才会把它们归并为一个逻辑好友，并且只按一次 Enter。任一
别名指向第二个身份或第二个会话时，整批计划会在首次点击前终止，不会猜测发送。
为让昵称或备注能够绑定到权威会话，每位目标好友还必须至少配置一个短号、抖音号
或 `sec_uid`；仅配置昵称/备注会保守终止，避免同名好友或迟到身份响应造成误发。

正式任务还会等待 IM SDK 明确返回“没有更多会话”，并要求 SDK 的有序会话列表与
页面 `data-index` 完整对应、两次全量扫描一致。扫描中、点击前或 Enter 前只要分页、
顺序、索引或身份发生变化，本轮就会保守终止；页面短暂静止不能替代分页终态证据。
